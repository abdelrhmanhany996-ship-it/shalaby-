# تفعيل الكتابة الصوتية والذكاء الاصطناعي

الميزة موجودة في الكود (`public/api/ai.php` + زر «تكلّم» و«حسّن النص»). تعمل في وضعين:

1. **بدون إعداد:** الميكروفون يستخدم الإملاء المدمج في المتصفح (`ar-EG`). الجودة متفاوتة وتعتمد على المتصفح (Chrome أفضل).
2. **بعد الإعداد (موصى به):** الصوت يُرسل لسيرفر الموقع ثم إلى نموذج Gemini الذي يفهم العامية المصرية، ويظهر زر «حسّن النص».

## الإعداد (مرة واحدة)
1. أنشئ مفتاحًا من https://aistudio.google.com/apikey
2. من hPanel ← File Manager، أنشئ الملف **خارج** `public_html`:
   `domains/<اسم الموقع>/crm-ai-secrets.php` (بجانب `public_html` وليس داخله)، مثلًا `domains/dev-shalaby.engsaber.space/` لموقع dev
   ```php
   <?php
   return [
     'gemini_key' => 'ضع المفتاح هنا',
     'model'      => 'gemini-flash-latest', // اختياري
   ];
   ```
3. لا تضع المفتاح في الريبو ولا في الكود. كل موقع يقرأ ملفه من فولدره (أو من `domains/` ليخدم المواقع كلها).

## الأمان
- المفتاح يبقى على السيرفر فقط، ولا يصل للمتصفح.
- كل طلب يحتاج Firebase ID token لموظف مسجّل دخوله، وبحد 60 طلبًا في الساعة لكل مستخدم.
- التسجيلات الصوتية لا تُحفظ، تُرسل للمعالجة فقط. أخبر الموظفين أن الصوت يُعالَج بخدمة خارجية.

## تبديل النموذج
غيّر `model` في ملف الإعداد (مثلًا لنموذج أدق). يمكن لاحقًا استبدال Gemini بمزود آخر (مثل Whisper أو gpt-4o-transcribe) بتعديل دالة `gemini()` في `ai.php` فقط.
