# Saber Group Subscriptions

منصة عربية (RTL) لإدارة اشتراكات أدوات الذكاء الاصطناعي: الفرق والمستخدمين والمحفظة بالدولار والجنيه وأكواد Google AI Pro / Plus.

React 19 + Vite + Tailwind CSS v4 + Firebase Firestore.

```bash
npm install --legacy-peer-deps
npm run dev      # تشغيل محلي
npm run build    # بناء ملفات الإنتاج في dist/
```

الاستضافة: موقع ثابت (static) على Hostinger.
